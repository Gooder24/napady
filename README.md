# Nápady: ideas up for adoption

*Nápady* is Slovak for "ideas". These are side projects I researched or started and will not continue. Each folder
holds the idea, the research behind it and how far it got. Take any of them: the texts are CC0, no permission or
credit needed. Code they link to keeps its own licence.

If you pick one up, opening an issue here to say so is welcome but not required.

| Idea | What | Got as far as |
|---|---|---|
| [Ownbeat](ownbeat/) | A local-first app that shows everything a watch's or ring's sensors can tell you, with a published method and a confidence for every number | Plan, metric catalogue with citations, device research, a working engine for Garmin FIT files |
